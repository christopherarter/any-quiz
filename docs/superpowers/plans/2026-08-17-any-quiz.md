# any-quiz Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a Claude skill that authors an ad-hoc quiz mid-conversation, serves it in the browser, and feeds the responses back into the session for coaching.

**Architecture:** A short-lived Node HTTP server bound to one quiz folder. Claude writes `meta.json` + `questions.json`, spawns the server as a background task, and stops. The user answers in a React SPA that autosaves drafts. On submit the server writes `answers.json`, prints a result JSON to stdout, and exits — the process exit is the handshake that returns control to Claude. Vite is build-time only so `serve.ts` keeps owning process lifetime; the built bundle is committed so the skill installs with a symlink and no `npm install`.

**Tech Stack:** TypeScript 7 strict · Node 22.18+ native type stripping (server runs `.ts` directly, no build) · React 19 · Vite 8 (build only) · Vitest 4 with node + jsdom projects · Testing Library · Biome 2.5 with `preset: "all"`.

**Spec:** `docs/superpowers/specs/2026-08-17-any-quiz-design.md`

## Global Constraints

- **Zero runtime dependencies.** `package.json` has no `dependencies` key at all. React and everything else are `devDependencies`, because the browser gets them pre-bundled in the committed `app/dist/`.
- **Node `>=22.18`.** Native TypeScript type stripping runs `serve.ts` with no build. Verified locally on Node 24.18.0.
- **Explicit import extensions everywhere** — `./quiz.ts`, `./Mcq.tsx`. Native type stripping requires it; Vite and Vitest accept it.
- **`erasableSyntaxOnly: true`.** No enums, namespaces, or parameter properties — type stripping cannot erase them, and this turns that into a type error instead of a runtime crash.
- **`verbatimModuleSyntax: true`.** Type-only imports must say `import type`.
- **Only `app/dist/` is built.** `serve.ts`, `lib/`, `test/`, and `tools/` run as TypeScript directly.
- **`app/dist/` is committed**, with stable (non-hashed) filenames and `.gitattributes` marking it generated.
- **stdout is a machine channel.** In `serve.ts` only the result JSON goes to stdout; every human-readable line goes to stderr.
- **The answer key never reaches the browser.** Stripped in the load path via `loadPublic`, and the browser is typed against `PublicQuestion` so reading `answer` is a compile error.
- **Bind `127.0.0.1` only.**
- **Exit codes:** `0` submitted · `2` invalid input or refused start · `3` abandoned.
- **6 question types:** `mcq`, `multi`, `blank`, `short`, `code`, `match`. **Closed (scored in code):** `mcq`, `multi`, `blank`, `match`. **Open (graded by Claude):** `short`, `code`.
- **No `order` type.** A drag-to-reorder list has no natural "untouched" state, so it either seeds an arrangement that counts as answered or needs a touched flag nothing else in the model uses. Cut from v1 rather than carry the asymmetry.
- **Every question type gets a component test** driving real interaction with `user-event` and asserting the exact `onChange` payload.
- **Biome `preset: "all"`**, nursery held at `recommended`. Exemptions must be named rules with a comment, never a group-wide `off`.
- **Quiz storage:** `~/.any-quiz/<YYYY-MM-DD>-<slug>-<id>/`, id is 4 hex chars.
- **Atomic writes** for `answers.json`: `.tmp` sibling then `renameSync`.

  id: string
  text: string
}

  id: string
  hint?: string
}

  id: string
  prompt: string
  rationale: string
  points?: number
}

export type Question =
  | (Base & { type: 'mcq'; choices: Choice[]; answer: string })
  | (Base & { type: 'multi'; choices: Choice[]; answer: string[] })
  | (Base & { type: 'blank'; blanks: Blank[]; answer: Record<string, string[]> })
  | (Base & { type: 'short'; answer: string })
  | (Base & { type: 'code'; language: string; answer: string })
  | (Base & { type: 'match'; left: Choice[]; right: Choice[]; answer: Record<string, string> })

export type QuestionType = Question['type']

export type AnswerValue = string | string[] | Record<string, string>

export interface ResponseEntry {

  parentQuizId: string | null
  targets: string[]
}

}

  auto: { correct: number; total: number; perQuestion: Record<string, boolean> }

import type { QuestionType } from './types.ts'

export const TYPES: QuestionType[] = ['mcq', 'multi', 'blank', 'short', 'code', 'match']

export class QuizError extends Error {
  readonly errors: string[]
  constructor(message: string, errors: string[] = []) {
    super(message)
    this.name = 'QuizError'
    this.errors = errors
  }
}

// Validation runs over untrusted JSON, so everything here is `unknown`-shaped on
// purpose. `Loose` is the shape we probe before we are entitled to a Question.
type Loose = Record<string, unknown>

const isString = (v: unknown): v is string => typeof v === 'string' && v.trim().length > 0
const asArray = (v: unknown): unknown[] => (Array.isArray(v) ? v : [])
const idsOf = (v: unknown): string[] =>
  asArray(v).map((x) => (x as Loose | null)?.id).filter(isString)
const placeholders = (prompt: string): string[] =>
  [...prompt.matchAll(/\{\{(\w+)\}\}/g)].map((m) => m[1] as string)
const sameSet = (a: string[], b: string[]): boolean =>
  a.length === b.length && [...a].sort().join('\u0000') === [...b].sort().join('\u0000')

function checkList(q: Loose, out: string[], field: string): boolean {
  const list = q[field]
  if (!Array.isArray(list) || list.length < 2) {
    out.push(`${String(q.id)}: ${field} must be an array of at least 2 entries`)
    return false
  }
  const ok = list.every((c) => isString((c as Loose)?.id) && isString((c as Loose)?.text))
  if (!ok) out.push(`${String(q.id)}: every ${field} entry needs a non-empty id and text`)
  return ok
}

const perType: Record<QuestionType, (q: Loose, out: string[]) => void> = {
  mcq(q, out) {
    if (!checkList(q, out, 'choices')) return
    if (!idsOf(q.choices).includes(q.answer as string)) {
      out.push(`${String(q.id)}: answer "${String(q.answer)}" is not a choice id`)
    }
  },
  multi(q, out) {
    if (!checkList(q, out, 'choices')) return
    if (!Array.isArray(q.answer) || q.answer.length === 0) {
      out.push(`${String(q.id)}: answer must be a non-empty array of choice ids`)
      return
    }
    for (const a of q.answer) {
      if (!idsOf(q.choices).includes(a as string)) {
        out.push(`${String(q.id)}: answer "${String(a)}" is not a choice id`)
      }
    }
  },
  blank(q, out) {
    const declared = idsOf(q.blanks)
    if (declared.length === 0) {
      out.push(`${String(q.id)}: blanks must be a non-empty array of {id, hint}`)
      return
    }
    if (!sameSet(placeholders(q.prompt as string), declared)) {
      out.push(`${String(q.id)}: prompt placeholders {{n}} do not match the blanks array`)
      return
    }
    const answer = q.answer as Record<string, unknown> | null
    if (!answer || typeof answer !== 'object' || !sameSet(Object.keys(answer), declared)) {
      out.push(`${String(q.id)}: answer keys must match the blanks array`)
      return
    }
    for (const [id, accept] of Object.entries(answer)) {
      if (!Array.isArray(accept) || accept.length === 0 || !accept.every(isString)) {
        out.push(`${String(q.id)}: blank "${id}" needs a non-empty accept-list of strings`)
      }
    }
  },
  short(q, out) {
    if (!isString(q.answer)) out.push(`${String(q.id)}: answer must be a non-empty reference answer`)
  },
  code(q, out) {
    if (!isString(q.language)) out.push(`${String(q.id)}: code questions need a language`)
    if (!isString(q.answer)) out.push(`${String(q.id)}: answer must be a non-empty reference solution`)
  },
  match(q, out) {
    if (!checkList(q, out, 'left')) return
    if (!checkList(q, out, 'right')) return
    const answer = q.answer as Record<string, unknown> | null
    if (!answer || typeof answer !== 'object' || !sameSet(Object.keys(answer), idsOf(q.left))) {
      out.push(`${String(q.id)}: answer keys must match the left ids`)
      return
    }
    for (const [l, r] of Object.entries(answer)) {
      if (!idsOf(q.right).includes(r as string)) {
        out.push(`${String(q.id)}: "${l}" maps to "${String(r)}", which is not a right id`)
      }
    }
  },
}

export function validateQuestions(doc: unknown): string[] {
  const out: string[] = []
  if (!doc || typeof doc !== 'object') return ['questions.json must be a JSON object']
  const { version, questions } = doc as Loose
  if (version !== 1) out.push(`unsupported version ${JSON.stringify(version)}, expected 1`)
  if (!Array.isArray(questions) || questions.length === 0) {
    out.push('questions must be an array with at least one entry')
    return out
  }

  const seen = new Set<string>()
  for (const [i, raw] of questions.entries()) {
    const q = (raw ?? {}) as Loose
    if (!isString(q.id)) {
      out.push(`question #${i + 1}: missing id`)
      continue
    }
    if (seen.has(q.id)) out.push(`${q.id}: duplicate id`)
    seen.add(q.id)
    if (!isString(q.prompt)) out.push(`${q.id}: missing prompt`)
    if (!TYPES.includes(q.type as QuestionType)) {
      out.push(`${q.id}: unknown type "${String(q.type)}"`)
      continue
    }
    if (q.answer === undefined) {
      out.push(`${q.id}: missing answer`)
      continue
    }
    perType[q.type as QuestionType](q, out)
  }
  return out
}

function readJson(path: string, label: string): unknown {
  let raw: string

    raw = readFileSync(path, 'utf8')

    throw new QuizError(`${label} is not valid JSON`, [(err as Error).message])

    const { answer: _answer, rationale: _rationale, ...rest } = q

import { existsSync, renameSync, writeFileSync } from 'node:fs'

export function answersPath(dir: string): string {
  return join(dir, 'answers.json')
}

function skeleton(quizId: string, questionIds: string[]): Answers {
  const now = new Date().toISOString()
  const responses: Record<string, ResponseEntry> = {}
  for (const id of questionIds) responses[id] = { value: null, flagged: false }
  return { quizId, status: 'draft', startedAt: now, updatedAt: now, submittedAt: null, responses }
}

export function readAnswers(dir: string, quizId: string, questionIds: string[]): Answers {
  const path = answersPath(dir)
  if (!existsSync(path)) return skeleton(quizId, questionIds)
  const saved = readJson(path, 'answers.json') as Answers
  saved.responses ??= {}
  for (const id of questionIds) saved.responses[id] ??= { value: null, flagged: false }
  return saved
}

export function writeAnswers(dir: string, answers: Answers): void {
  answers.updatedAt = new Date().toISOString()
  const path = answersPath(dir)
  const tmpPath = `${path}.tmp`
  writeFileSync(tmpPath, `${JSON.stringify(answers, null, 2)}\n`)
  renameSync(tmpPath, path)
}

export function archiveAnswers(dir: string): string {
  const path = answersPath(dir)
  const saved = readJson(path, 'answers.json') as Answers
  const stamp = (saved.submittedAt ?? new Date().toISOString())
    .replace(/[-:]/g, '')
    .replace(/\.\d+Z$/, 'Z')
  const target = join(dir, `answers-${stamp}.json`)
  renameSync(path, target)
  return target
}

import type { AnswerValue, Question, QuestionType, ResponseEntry, ResultPayload } from './types.ts'

export const CLOSED_TYPES: ReadonlySet<QuestionType> = new Set<QuestionType>([
  'mcq',
  'multi',
  'blank',
  'match',
])

export function normalizeText(s: string): string {
  return s.trim().toLowerCase().replace(/\s+/g, ' ')
}

const asStrings = (v: AnswerValue): string[] => (Array.isArray(v) ? v : [])
const asRecord = (v: AnswerValue): Record<string, string> =>
  typeof v === 'object' && v !== null && !Array.isArray(v) ? v : {}

export function scoreQuestion(question: Question, value: AnswerValue | null): boolean {
  if (value === null) return false
  switch (question.type) {
    case 'mcq':
      return value === question.answer
    case 'multi': {
      const got = asStrings(value)
      return (
        got.length === question.answer.length &&
        [...got].sort().join('\u0000') === [...question.answer].sort().join('\u0000')
      )
    }
    case 'blank': {
      const got = asRecord(value)
      return Object.entries(question.answer).every(([id, accept]) => {
        const typed = got[id]
        return typeof typed === 'string' && accept.some((a) => normalizeText(a) === normalizeText(typed))
      })
    }
    case 'match': {
      const got = asRecord(value)
      return Object.entries(question.answer).every(([l, r]) => got[l] === r)
    }
    // `short` and `code` are graded by Claude, never here.
    case 'short':
    case 'code':
      return false
  }
}

export function scoreQuiz(
  questions: Question[],
  responses: Record<string, ResponseEntry>,
): Pick<ResultPayload, 'auto' | 'needsGrading' | 'flagged'> {
  const perQuestion: Record<string, boolean> = {}
  const needsGrading: string[] = []
  const flagged: string[] = []
  let correct = 0
  let total = 0

  for (const question of questions) {
    const entry = responses[question.id]
    if (entry?.flagged === true) flagged.push(question.id)
    if (!CLOSED_TYPES.has(question.type)) {
      needsGrading.push(question.id)
      continue
    }
    total += 1
    const ok = scoreQuestion(question, entry?.value ?? null)
    perQuestion[question.id] = ok
    if (ok) correct += 1
  }

  return { auto: { correct, total, perQuestion }, needsGrading, flagged }
}

import { createHash } from 'node:crypto'
import { existsSync, readdirSync, readFileSync, statSync } from 'node:fs'
import { join, relative } from 'node:path'
import { fileURLToPath } from 'node:url'

const ROOT = fileURLToPath(new URL('..', import.meta.url))
const APP_DIR = join(ROOT, 'app')

export const DIST_DIR = join(APP_DIR, 'dist')
const STAMP = join(DIST_DIR, '.buildinfo.json')

// Anything Vite bundles into app/dist. Tests are excluded: they never ship, so a
// test-only edit must not mark the committed bundle stale.
const SOURCE_EXTENSIONS = ['.ts', '.tsx', '.css', '.html']
const isSource = (path: string): boolean =>
  SOURCE_EXTENSIONS.some((ext) => path.endsWith(ext)) && !/\.test\.tsx?$/.test(path)

function walk(dir: string, out: string[] = []): string[] {
  for (const entry of readdirSync(dir).sort()) {
    if (entry === 'dist' || entry === 'node_modules') continue
    const path = join(dir, entry)
    if (statSync(path).isDirectory()) walk(path, out)
    else if (isSource(path)) out.push(path)
  }
  return out
}

export function sourceHash(): string {
  const hash = createHash('sha256')
  for (const path of walk(APP_DIR)) {
    hash.update(relative(ROOT, path))
    hash.update('\u0000')
    hash.update(readFileSync(path))
    hash.update('\u0000')
  }
  return hash.digest('hex')
}

export function readStampedHash(): string | null {
  if (!existsSync(STAMP)) return null
  try {
    const parsed = JSON.parse(readFileSync(STAMP, 'utf8')) as { sourceHash?: unknown }
    return typeof parsed.sourceHash === 'string' ? parsed.sourceHash : null
  } catch {
    return null
  }
}

export function isDistFresh(): boolean {
  const stamped = readStampedHash()
  return stamped !== null && stamped === sourceHash()
}

import { existsSync, readFileSync, statSync } from 'node:fs'
import { createServer as httpCreateServer, type Server, type ServerResponse } from 'node:http'
import { extname, join, normalize } from 'node:path'
import { DIST_DIR } from './buildinfo.ts'
import { loadPublic } from './quiz.ts'

const MIME: Record<string, string> = {
  '.html': 'text/html; charset=utf-8',
  '.js': 'text/javascript; charset=utf-8',
  '.css': 'text/css; charset=utf-8',
  '.json': 'application/json; charset=utf-8',
  '.svg': 'image/svg+xml',
}

function sendJson(res: ServerResponse, status: number, body: unknown): void {
  const payload = JSON.stringify(body)
  res.writeHead(status, {
    'content-type': MIME['.json'] as string,
    'content-length': Buffer.byteLength(payload),
  })
  res.end(payload)
}

function sendText(res: ServerResponse, status: number, text: string): void {
  res.writeHead(status, { 'content-type': 'text/plain; charset=utf-8' })
  res.end(text)
}

function serveStatic(res: ServerResponse, urlPath: string): void {
  const rel = normalize(urlPath === '/' ? '/index.html' : urlPath).replace(/^(\.\.[/\\])+/, '')
  const path = join(DIST_DIR, rel)
  if (!path.startsWith(DIST_DIR)) {
    sendText(res, 400, 'bad path')
    return
  }
  if (!existsSync(path) || !statSync(path).isFile()) {
    sendText(res, 404, 'not found')
    return
  }
  res.writeHead(200, {
    'content-type': MIME[extname(path)] ?? 'application/octet-stream',
    'cache-control': 'no-store',
  })
  res.end(readFileSync(path))
}

export function createServer({ dir }: { dir: string }): Server {
  return httpCreateServer((req, res) => {
    const url = new URL(req.url ?? '/', 'http://127.0.0.1')

    if (url.pathname === '/api/quiz' && req.method === 'GET') {
      sendJson(res, 200, loadPublic(dir))
      return
    }
    if (url.pathname.startsWith('/api/')) {
      sendJson(res, 404, { error: 'unknown endpoint' })
      return
    }
    if (req.method !== 'GET') {
      sendText(res, 405, 'method not allowed')
      return
    }
    serveStatic(res, url.pathname)
  })
}

```ts
import type { IncomingMessage } from 'node:http'
import { loadFull, loadPublic, readAnswers, writeAnswers } from './quiz.ts'
import type { ResponseEntry } from './types.ts'

const MAX_BODY = 1_000_000

function readBody(req: IncomingMessage): Promise<string> {
  return new Promise((resolve, reject) => {
    let size = 0
    const chunks: Buffer[] = []
    req.on('data', (chunk: Buffer) => {
      size += chunk.length
      if (size > MAX_BODY) {
        req.destroy()
        reject(new Error('body too large'))
        return
      }
      chunks.push(chunk)
    })
    req.on('end', () => resolve(Buffer.concat(chunks).toString('utf8')))
    req.on('error', reject)
  })
}

export function createServer({ dir }: { dir: string }): Server {
  const { meta, questions } = loadFull(dir)
  const questionIds = questions.map((q) => q.id)
  const known = new Set(questionIds)

  const server = httpCreateServer((req, res) => {
    void (async () => {
      const url = new URL(req.url ?? '/', 'http://127.0.0.1')

      if (url.pathname === '/api/quiz' && req.method === 'GET') {
        sendJson(res, 200, loadPublic(dir))
        return
      }

      if (url.pathname === '/api/answers' && req.method === 'GET') {
        sendJson(res, 200, readAnswers(dir, meta.id, questionIds))
        return
      }

      if (url.pathname === '/api/answers' && req.method === 'PUT') {
        let patch: { responses?: Record<string, ResponseEntry> }
        try {
          patch = JSON.parse(await readBody(req))
        } catch {
          sendJson(res, 400, { error: 'malformed JSON body' })
          return
        }
        const incoming = patch.responses
        if (!incoming || typeof incoming !== 'object') {
          sendJson(res, 400, { error: 'body must be {responses: {...}}' })
          return
        }
        const unknown = Object.keys(incoming).filter((id) => !known.has(id))
        if (unknown.length > 0) {
          sendJson(res, 400, { error: `unknown question ids: ${unknown.join(', ')}` })
          return
        }
        const answers = readAnswers(dir, meta.id, questionIds)
        for (const [id, entry] of Object.entries(incoming)) {
          answers.responses[id] = { value: entry?.value ?? null, flagged: entry?.flagged === true }
        }
        writeAnswers(dir, answers)
        res.writeHead(204)
        res.end()
        return
      }

      if (url.pathname.startsWith('/api/')) {
        sendJson(res, 404, { error: 'unknown endpoint' })
        return
      }
      if (req.method !== 'GET') {
        sendText(res, 405, 'method not allowed')
        return
      }
      serveStatic(res, url.pathname)
    })()
  })

  return server
}
```

const LAUNCHER: Record<string, string> = { darwin: 'open', win32: 'start', linux: 'xdg-open' }

export function openBrowser(url: string): boolean {
  const cmd = LAUNCHER[process.platform]
  if (cmd === undefined) return false

    spawn(cmd, [url], {

      detached: true,
      shell: process.platform === 'win32',
    }).unref()

#!/usr/bin/env node
import { existsSync } from 'node:fs'
import { DIST_DIR, isDistFresh } from './lib/buildinfo.ts'
import { openBrowser } from './lib/open.ts'
import { answersPath, archiveAnswers, loadFull, QuizError, readAnswers } from './lib/quiz.ts'
import { createServer } from './lib/server.ts'
import type { ResultPayload } from './lib/types.ts'

export interface Options {
  dir: string | null
  port: number
  open: boolean
  retake: boolean
}

export function parseArgs(argv: string[]): Options {
  const out: Options = { dir: null, port: 0, open: true, retake: false }
  for (let i = 0; i < argv.length; i += 1) {
    const arg = argv[i]
    if (arg === '--port') {
      i += 1
      out.port = Number(argv[i])
    } else if (arg === '--no-open') out.open = false
    else if (arg === '--retake') out.retake = true
    else if (out.dir === null && arg !== undefined) out.dir = arg
  }
  return out
}

const log = (msg: string): void => {
  process.stderr.write(`${msg}\n`)
}

function fail(message: string, errors: string[] = []): never {
  log(`any-quiz: ${message}`)
  for (const e of errors) log(`  - ${e}`)
  process.exit(2)
}

function main(): void {
  const opts = parseArgs(process.argv.slice(2))
  if (opts.dir === null) {
    fail('usage: serve.ts <quiz-dir> [--port N] [--no-open] [--retake]')
  }
  const dir = opts.dir

  if (!existsSync(DIST_DIR)) fail('the frontend bundle is missing — run `npm run build`')
  if (!isDistFresh()) log('any-quiz: warning — app/dist is stale; run `npm run build`')

  let meta: ReturnType<typeof loadFull>['meta']
  let questions: ReturnType<typeof loadFull>['questions']
  try {
    ;({ meta, questions } = loadFull(dir))
  } catch (err) {
    if (err instanceof QuizError) fail(err.message, err.errors)
    throw err
  }

  if (existsSync(answersPath(dir))) {
    const existing = readAnswers(dir, meta.id, questions.map((q) => q.id))
    if (existing.status === 'submitted') {
      if (!opts.retake) {
        fail('this quiz was already submitted; pass --retake to start a fresh attempt')
      }
      log(`any-quiz: archived the previous attempt to ${archiveAnswers(dir)}`)
    }
  }

  const server = createServer({ dir })

  server.on('submitted', (payload: ResultPayload) => {
    process.stdout.write(`${JSON.stringify(payload, null, 2)}\n`)
    server.close(() => process.exit(0))
  })

  for (const signal of ['SIGINT', 'SIGTERM'] as const) {
    process.on(signal, () => {
      log('any-quiz: abandoned; the draft is saved and the quiz can be re-served')
      server.close(() => process.exit(3))
      setTimeout(() => process.exit(3), 200).unref()
    })
  }

  server.on('error', (err: NodeJS.ErrnoException) => {
    if (err.code === 'EADDRINUSE' && opts.port !== 0) {
      log(`any-quiz: port ${opts.port} is busy, falling back to an ephemeral port`)
      server.listen(0, '127.0.0.1')
      return
    }
    fail(err.message)
  })

  server.listen(opts.port, '127.0.0.1', () => {
    const address = server.address()
    if (address === null || typeof address === 'string') return
    const url = `http://127.0.0.1:${address.port}`
    log(`any-quiz: ${meta.title} — ${questions.length} questions`)
    log(`any-quiz: ${url}`)
    if (opts.open && !openBrowser(url)) {
      log('any-quiz: could not launch a browser; open the URL above')
    }
  })
}

if (process.argv[1] !== undefined && import.meta.filename === process.argv[1]) {
  main()
}

export type Segment = { kind: 'text'; value: string } | { kind: 'blank'; id: string }

export function parseBlanks(prompt: string): Segment[] {
  const segments: Segment[] = []
  let last = 0
  for (const match of prompt.matchAll(/\{\{(\w+)\}\}/g)) {
    const start = match.index
    if (start > last) segments.push({ kind: 'text', value: prompt.slice(last, start) })
    segments.push({ kind: 'blank', id: match[1] as string })
    last = start + match[0].length
  }
  if (last < prompt.length) segments.push({ kind: 'text', value: prompt.slice(last) })
  return segments
}

```ts
import type { AnswerValue, PublicQuestion, ResponseEntry } from '../../lib/types.ts'

const filled = (v: unknown): v is string => typeof v === 'string' && v.trim().length > 0
const asRecord = (v: AnswerValue): Record<string, string> =>
  typeof v === 'object' && !Array.isArray(v) ? v : {}

export function isAnswered(question: PublicQuestion, value: AnswerValue | null): boolean {
  if (value === null) return false
  switch (question.type) {
    case 'mcq':
    case 'short':
    case 'code':
      return filled(value)
    case 'multi':
      return Array.isArray(value) && value.length > 0
    case 'blank':
      return question.blanks.every((b) => filled(asRecord(value)[b.id]))
    case 'match':
      return question.left.every((l) => filled(asRecord(value)[l.id]))
  }
}

export function summarize(
  questions: PublicQuestion[],
  responses: Record<string, ResponseEntry>,
): { answered: number; total: number; flagged: number } {
  let answered = 0
  let flagged = 0
  for (const question of questions) {
    const entry = responses[question.id]
    if (isAnswered(question, entry?.value ?? null)) answered += 1
    if (entry?.flagged === true) flagged += 1
  }
  return { answered, total: questions.length, flagged }
}

import { useCallback, useEffect, useRef, useState } from 'react'
import type { AnswerValue, Answers, Meta, PublicQuestion, ResponseEntry } from '../lib/types.ts'

const AUTOSAVE_MS = 500

interface QuizData {
  meta: Meta
  questions: PublicQuestion[]
}

export function useQuiz() {
  const [status, setStatus] = useState<'loading' | 'ready' | 'submitted'>('loading')
  const [data, setData] = useState<QuizData | null>(null)
  const [responses, setResponses] = useState<Record<string, ResponseEntry>>({})
  const timer = useRef<ReturnType<typeof setTimeout> | null>(null)

  useEffect(() => {
    let cancelled = false
    void (async () => {
      const [quiz, answers] = await Promise.all([
        fetch('/api/quiz').then((r) => r.json() as Promise<QuizData>),
        fetch('/api/answers').then((r) => r.json() as Promise<Answers>),
      ])
      if (cancelled) return
      setData(quiz)
      setResponses(answers.responses)
      setStatus(answers.status === 'submitted' ? 'submitted' : 'ready')
    })()
    return () => {
      cancelled = true
    }
  }, [])

  const save = useCallback((id: string, entry: ResponseEntry) => {
    if (timer.current !== null) clearTimeout(timer.current)
    timer.current = setTimeout(() => {
      void fetch('/api/answers', {
        method: 'PUT',
        headers: { 'content-type': 'application/json' },
        body: JSON.stringify({ responses: { [id]: entry } }),
      }).catch(() => undefined)
    }, AUTOSAVE_MS)
  }, [])

  const setValue = useCallback(
    (id: string, value: AnswerValue) => {
      setResponses((prev) => {
        const entry = { value, flagged: prev[id]?.flagged === true }
        save(id, entry)
        return { ...prev, [id]: entry }
      })
    },
    [save],
  )

  const toggleFlag = useCallback(
    (id: string) => {
      setResponses((prev) => {
        const entry = { value: prev[id]?.value ?? null, flagged: !(prev[id]?.flagged === true) }
        save(id, entry)
        return { ...prev, [id]: entry }
      })
    },
    [save],
  )

  const submit = useCallback(async () => {
    if (timer.current !== null) clearTimeout(timer.current)
    await fetch('/api/answers', {
      method: 'PUT',
      headers: { 'content-type': 'application/json' },
      body: JSON.stringify({ responses }),
    })
    await fetch('/api/submit', { method: 'POST' })
    setStatus('submitted')
  }, [responses])

  return {
    status,
    meta: data?.meta ?? null,
    questions: data?.questions ?? [],
    responses,
    setValue,
    toggleFlag,
    submit,
  }
}

import type { Narrow, QuestionProps } from './types.ts'

export function Multi({ question, value, onChange }: QuestionProps<Narrow<'multi'>, string[]>) {
  const selected = new Set(value ?? [])

  const toggle = (id: string) => {
    const next = new Set(selected)
    if (next.has(id)) next.delete(id)
    else next.add(id)
    // Emit in choice order so the payload is stable no matter what order boxes were clicked.
    onChange(question.choices.map((c) => c.id).filter((c) => next.has(c)))
  }

  return (
    <div>
      {question.choices.map((choice) => (
        <label className="opt" key={choice.id}>
          <input
            checked={selected.has(choice.id)}
            onChange={() => toggle(choice.id)}
            type="checkbox"
            value={choice.id}
          />
          {choice.text}
        </label>
      ))}
    </div>
  )
}

import { parseBlanks } from '../lib/blanks.ts'
import type { Narrow, QuestionProps } from './types.ts'

export function Blank({
  question,
  value,
  onChange,
}: QuestionProps<Narrow<'blank'>, Record<string, string>>) {
  const current = value ?? {}
  const hints = new Map(question.blanks.map((b) => [b.id, b.hint ?? '']))

  return (
    <p className="q-prompt">
      {parseBlanks(question.prompt).map((segment, index) =>
        segment.kind === 'text' ? (
          // biome-ignore lint/suspicious/noArrayIndexKey: prompt segments are positional and static
          <span key={index}>{segment.value}</span>
        ) : (
          <input
            aria-label={`blank ${segment.id}: ${hints.get(segment.id) ?? ''}`}
            className="blank"
            key={segment.id}
            onChange={(e) => onChange({ ...current, [segment.id]: e.target.value })}
            placeholder={hints.get(segment.id)}
            type="text"
            value={current[segment.id] ?? ''}
          />
        ),
      )}
    </p>
  )
}

import type { KeyboardEvent } from 'react'
import type { Narrow, QuestionProps } from './types.ts'

export function Code({ question, value, onChange }: QuestionProps<Narrow<'code'>, string>) {
  const current = value ?? ''

  // Tab indents rather than moving focus out of the editor.
  const onKeyDown = (event: KeyboardEvent<HTMLTextAreaElement>) => {
    if (event.key !== 'Tab' || event.shiftKey) return
    event.preventDefault()
    const area = event.currentTarget
    const { selectionStart: start, selectionEnd: end } = area
    onChange(`${current.slice(0, start)}  ${current.slice(end)}`)
  }

  return (
    <div>
      <span className="q-type">{question.language}</span>
      <textarea
        aria-label={question.prompt}
        className="code"
        onChange={(e) => onChange(e.target.value)}
        onKeyDown={onKeyDown}
        placeholder={`// ${question.language}`}
        spellCheck={false}
        value={current}
      />
    </div>
  )
}

import type { Narrow, QuestionProps } from './types.ts'

export function Match({
  question,
  value,
  onChange,
}: QuestionProps<Narrow<'match'>, Record<string, string>>) {
  const current = value ?? {}

  const choose = (leftId: string, rightId: string) => {
    const next = { ...current }
    if (rightId === '') delete next[leftId]
    else next[leftId] = rightId
    onChange(next)
  }

  return (
    <div>
      {question.left.map((left) => (
        <div className="match-row" key={left.id}>
          <span>{left.text}</span>
          <span aria-hidden="true">—</span>
          <select
            aria-label={`match for ${left.text}`}
            onChange={(e) => choose(left.id, e.target.value)}
            value={current[left.id] ?? ''}
          >
            <option value="">choose…</option>
            {question.right.map((right) => (
              <option key={right.id} value={right.id}>
                {right.text}
              </option>
            ))}
          </select>
        </div>
      ))}
    </div>
  )
}

  "quizDir": "/Users/you/.any-quiz/2026-08-17-rust-lifetimes-a3f9",

  "needsGrading": ["q4", "q6"],
  "flagged": ["q3"],
  "responses": { "q1": { "value": "b", "flagged": false } }
}
```

Then:

1. Read `questions.json` from `quizDir` — it holds the `answer` and `rationale` for every question.
2. Grade the `needsGrading` questions (`short` and `code`) against their reference answers. Be generous about phrasing, strict about substance.
3. Coach across all results, weighting by signal rather than correctness alone:
   - **wrong and not flagged** — a confident misconception. Lead here; it is the most valuable thing on the page.
   - **wrong and flagged** — they knew they were guessing. Teach the concept plainly.
   - **right and flagged** — a lucky guess or shaky instinct. Confirm *why* it was right so it sticks.
   - **right and not flagged** — acknowledge briefly and move on. Do not pad.
4. Offer a follow-up quiz targeting what they missed.

Exit code `3` means they closed it without submitting. Say so and offer to re-serve the same folder — the draft is intact.

### 4. Follow-up quizzes

Same procedure, with `meta.json` setting `parentQuizId` to the previous quiz's `id` and `targets` to the missed question ids.

## Question schema

`questions.json` is `{"version": 1, "questions": [...]}`. Every question needs `id`, `type`, `prompt`, `answer`, `rationale`.

`rationale` is your note to yourself explaining why the answer is correct. Write it as if a future session with no memory of this conversation will grade the quiz — because that can happen.

| type | extra fields | `answer` |
|---|---|---|
| `mcq` | `choices: [{id, text}]` (2+) | choice id: `"b"` |
| `multi` | `choices: [{id, text}]` (2+) | choice ids: `["a", "c"]` |
| `blank` | prompt has `{{1}}`, `{{2}}`; `blanks: [{id, hint}]` | accept-lists: `{"1": ["complete", "complete binary"]}` |
| `short` | — | reference prose answer |
| `code` | `language` | reference solution |
| `match` | `left: [{id,text}]`, `right: [{id,text}]` (2+ each) | `{"l1": "r3"}` |

Rules the validator enforces — a violation exits `2` and serves nothing:

- `blank` prompt placeholders must exactly match the `blanks` array ids, and `answer` keys must too.
- Every `blank` accept-list must be a non-empty array of strings. List real synonyms; matching folds case and collapses whitespace but is otherwise exact.
- `match` `answer` keys must be exactly the left ids, and every value must be a right id.
- Question ids must be unique.

`mcq` and `multi` choices render in written order, so vary where the correct answer sits.

## Flags

| flag | effect |
|---|---|
| `--retake` | required to re-serve an already-submitted quiz; archives the previous attempt |
| `--port N` | pin a port (falls back to an ephemeral one if busy) |
| `--no-open` | do not launch a browser |

## Exit codes

`0` submitted · `2` invalid quiz or refused start · `3` abandoned
